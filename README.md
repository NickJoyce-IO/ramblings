# Ramblings

A personal blog on applying AI-assisted development inside UK Government constraints, and a place to get hands-on with code again. Built with [Astro](https://astro.build), deployed to GitHub Pages.

Views are my own. See `CONTEXT.md` for the language used in this project and `docs/adr/` for the decisions behind it.

## Commands

| Command           | Action                                      |
| :---------------- | :------------------------------------------ |
| `npm install`     | Install dependencies                        |
| `npm run dev`     | Start the dev server at `localhost:4321`    |
| `npm run build`   | Build the production site to `./dist/`      |
| `npm run preview` | Preview the production build locally        |
